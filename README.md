# Requirement Classification from Technical Specifications

This project takes a real technical specification (the **NVMe spec**), parses it
with **Docling**, and trains machine-learning models to classify each extracted
requirement sentence by its **normative modality**
(`MANDATORY` / `PROHIBITED` / `RECOMMENDED` / `OPTIONAL` / `INFORMATIVE`).

It implements two phases of a larger Document-to-Code Agent:

* **Phase 1 — Document understanding:** Docling → structured markdown/JSON →
  sentence-level records with page & section provenance.
* **Phase 2 — Requirement classification (the ML core):** a **DistilBERT**
  fine-tune benchmarked against **classical baselines** (Naive Bayes, Logistic
  Regression, Linear SVM) with cross-validation and full evaluation.

The trained classifier is what turns raw parsed spec text into the structured,
typed requirements a downstream code/test-generation agent would consume.

## Pipeline

```
data/raw/*.pdf
      │  Docling
      ▼
data/parsed/*.md + records.json        (Phase 1  -- src/parse.py)
      │  weak modality labeling
      ▼
data/dataset/{train,val,test}.csv      (Phase 2  -- src/build_dataset.py)
      │
      ├── TF-IDF + NB / LogReg / SVM    (Phase 4a -- src/baseline.py)
      └── DistilBERT fine-tune          (Phase 4b -- src/transformer_model.py)
      │
      ▼
outputs/  metrics (JSON) + figures (confusion, ROC, PR, comparison)
```

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Run

1. Put your NVMe spec pages in `data/raw/` (see [`data/README.md`](data/README.md)).
2. Run the full pipeline:

```bash
python -m scripts.run_pipeline                  # parse + dataset + both models + compare
python -m scripts.run_pipeline --skip-transformer   # classical only (fast)
python -m scripts.run_pipeline --mask-modals        # context-only ablation
python -m scripts.run_pipeline --epochs 4 --batch-size 16
```

Individual stages:

```bash
python -m src.parse            # Phase 1: Docling parse
python -m src.build_dataset    # Phase 2: label + split
python -m src.eda              # EDA figures (class dist, correlation heatmap, ...)
python -m src.baseline         # Phase 4a: classical baseline
python -m src.transformer_model --epochs 10  # Phase 4b: DistilBERT
python -m src.tuning           # grid-search hyperparameter tuning
python -m src.feature_importance   # LogReg feature weights + learning curve
```

## Outputs

```
outputs/metrics/   metrics_<model>.json, comparison.json
```

## Project layout

```
  config.py            paths, label schema, modality lexicon, hyperparams
  parse.py             Phase 1  -- Docling parsing + sentence extraction
  build_dataset.py     Phase 2  -- weak labeling + stratified splits
  eda.py               exploratory analysis + engineered-feature figures
  baseline.py          Phase 4a -- TF-IDF classical models + CV
  transformer_model.py Phase 4b -- DistilBERT fine-tuning
  tuning.py            grid-search hyperparameter tuning
  feature_importance.py LogReg feature weights + learning curve
  evaluation.py        shared metrics + plots
scripts/
  run_pipeline.py      end-to-end driver
  make_final_report.py builds the final report PDF from live metrics/figures
  make_slides.py       builds the final presentation (.pptx)
notebooks/
  results_summary.ipynb  loads metrics/figures and summarizes results
data/                  raw / parsed / dataset  (see data/README.md)
outputs/               metrics, figures, models
```
